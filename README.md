# Bot Ambiental

**Um bot para Discord criado em Python com o objetivo de conscientizar as pessoas sobre as mudanças climáticas e incentivar pequenas atitudes que ajudam a proteger o meio ambiente.**

## Objetivo

O EcoBot busca ajudar os usuários a aprender mais sobre:

- Mudanças climáticas
- Reciclagem
- Economia de água
- Economia de energia
- Transportes sustentáveis
- Importância das árvores
- Descarte correto de resíduos

## Comandos

- #ola	Apresenta o bot ao usuário.
- #lixo	Mostra as cores das lixeiras e os materiais correspondentes.
- #dicas	Envia uma dica aleatória para ajudar o meio ambiente.
- #reciclar <item>	Informa em qual lixeira determinado material deve ser descartado.
- #decompositar <item>	Informa aproximadamente quanto tempo um material pode levar para se decompor.
- #desafio	Cria um desafio ambiental para o usuário realizar.
- #quiz	Faz perguntas sobre meio ambiente e mudanças climáticas.
- #energia	Fornece dicas para economizar energia.
- #agua	Fornece dicas para economizar água.
- #transporte	Mostra alternativas de transporte mais sustentáveis.
- #arvore	Explica a importância das árvores para o meio ambiente.
- #clima	Explica o que são as mudanças climáticas e seus impactos.

### Como o bot ajuda?

O bot procura transformar informação em ação. Em vez de apenas explicar o problema das mudanças climáticas, ele incentiva o usuário a adotar hábitos mais sustentáveis no dia a dia.

*Por exemplo:*

🌱 Desafio ambiental:
Hoje, tente economizar água durante suas atividades!

## Conclusão

**O Bot Ambiental é uma ferramenta educativa que utiliza a tecnologia para conscientizar, ensinar e incentivar atitudes sustentáveis, mostrando que pequenas ações podem contribuir para a proteção do meio ambiente e ajudar o mundo!!**
